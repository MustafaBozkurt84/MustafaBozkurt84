## Pipeline Run

Profile READMEs are usually a wall of badges, so I put a game in mine instead.

You are a record travelling down a pipe. Catch the ones in front of you, stay off the
nulls. Three nulls and the job ends up in the dead letter queue.

<p align="center">
  <b><a href="https://mustafabozkurt84.github.io/MustafaBozkurt84/">▶ Play it</a></b>
  &nbsp;·&nbsp; arrow keys or <code>A</code>/<code>D</code> &nbsp;·&nbsp; tap left or right on a phone
</p>

No engine, no dependencies, no build step. One HTML file, a canvas, and about 500 lines
of hand-written perspective projection — every cube in there is eight points divided by
their own depth. The lattice up top is the same trick with the JavaScript removed: a
3×3×3 grid rotated with real 3D maths, then baked into an SVG that animates on its own.

Both are in this repo if you want to pull them apart —
[`index.html`](index.html) and [`assets/hero.svg`](assets/hero.svg).
